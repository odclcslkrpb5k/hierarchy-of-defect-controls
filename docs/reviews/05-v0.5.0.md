## 1. Correctness

### R7 (carried over). Perl switch-parsing tests were deleted — should fix

- **Where:** [test/run_tests.py](hierarchy-of-defect-controls/test/run_tests.py). `grep -c perl test/run_tests.py` → `0` (ran).
- **What happened:** v0.4.0 had four tests that protected the fix for round 3's R2a:
  - `test_r4_1_readonly_perl_with_I_never_flagged`
  - `test_r4_2_perl_M_switches_not_flagged`
  - `test_r4_3_perl_pi_noop_flagged_and_denied`
  - `test_r4_4_perl_i_bak_noop_and_real_edit`

  v0.5.0 replaced the patch tests and removed these four with them. The test count stayed at 41 only because new patch tests took their place.
- **Risk:** `perl_inplace` and `sed_inplace` ([scripts/hdc_hooks.py:186-224](hierarchy-of-defect-controls/scripts/hdc_hooks.py#L186-L224)) are the code that produced R2a. They now have no direct test. A later edit could reintroduce "`-Ilib` counts as `-i`" and the suite would still pass.
- **Behaviour today is correct:** N1 ran clean, and real-session steps 4–9 behaved as expected. This is a coverage gap, not a defect.
- **Fix:** restore the four tests unchanged. Their text is in the v0.4.0 tree; the cases are also listed in [Reproduction](#r7-perl-cases-to-restore).

### R6 (residual). Durations written against their unit give every run a new signature — low, fails open

- **Where:** `normalise_line`, [scripts/hdc_hooks.py:89-101](hierarchy-of-defect-controls/scripts/hdc_hooks.py#L89-L101). `\b\d+\b` does not match digits followed directly by a letter, so `5007ms` and `2033ms` are kept as they are.
- **Failure mode:** if the signature line contains a measured duration, each run records a different signature. The count restarts every time, so the gate never arms and the reminder never fires.
  - **Error-like lines:** affected since the v0.3.0 normaliser.
  - **Output with no error-like line:** new in v0.5.0. The fallback now adds the *last* non-decoration line, which for tools like `ping` is a statistics line with a duration. v0.4.0 used only the first line (`return candidates[:1]`, traced from the v0.4.0 source read in round 4).
- **Confirmed (ran):**

  | Error text per run | Attempts 1–4 |
  |---|---|
  | `Error: request timed out after 5003ms` / `5011ms` / `5002ms` / `5007ms` | failed, failed, failed, failed: never armed |
  | `ping` output ending `100% packet loss, time 2033ms` / `2041ms` / `2029ms` / `2037ms` (no error-like line) | failed ×4: never armed |
  | Control: `… timed out after 5003 ms` (space before unit) | failed, reminder, **denied** |

- **Severity:** low. It fails open (no false denial), but it misses the transient-timeout retry loop the gate exists for.
- **Fix:** before the `\b\d+\b` rule, normalise numbers glued to a unit, e.g. `re.sub(r"\b\d+(?:\.\d+)?(ns|us|µs|ms|s|m|h|kb|mb|gb|k|b)\b", r"<n>\1", s)`. Add the three rows above as tests.

### Hygiene — low

A tarball built from the directory would include a stray `__pycache__`. [README.md:64](hierarchy-of-defect-controls/README.md#L64) says it is "excluded from the package". Today no `__pycache__` exists, and the suite doesn't create one (ran). Either build the tgz with `--exclude=__pycache__`, or reword the claim.

## Reproduction

### Harness

Same as round 4.

```python
import json, os, subprocess, tempfile
S = "/abs/path/hierarchy-of-defect-controls/scripts/hdc_hooks.py"
base = tempfile.mkdtemp()
N = [0]

def sh(cmd, cwd): return subprocess.run(cmd, shell=True, cwd=cwd, capture_output=True, text=True)
def hook(mode, p): return subprocess.run(["python3", S, mode], input=json.dumps(p), capture_output=True, text=True).stdout

def bash(cwd, sid, cmd, raw_err=None):
    N[0] += 1
    p = {"session_id": sid, "cwd": cwd, "scratchpad_dir": base, "tool_name": "Bash",
         "tool_input": {"command": cmd, "description": "d"}, "tool_use_id": f"toolu_{N[0]}"}
    if "deny" in hook("gate", {**p, "hook_event_name": "PreToolUse"}): return "DENIED", ""
    res = sh(cmd, cwd)
    if res.returncode == 0:
        out = hook("success", {**p, "hook_event_name": "PostToolUse",
                               "tool_response": {"stdout": res.stdout, "stderr": res.stderr, "interrupted": False}})
    else:
        out = hook("failure", {**p, "hook_event_name": "PostToolUseFailure",
                               "error": raw_err or f"Exit code {res.returncode}\n{res.stdout}{res.stderr}".strip()})
    return f"exit={res.returncode}", (json.loads(out)["hookSpecificOutput"]["additionalContext"] if out else "")
```
